# Omni Media assets

Video files for Omnisoft's scheduled social posts (YouTube Shorts, TikTok, X).

This repository is **file hosting only**. It is not a tool or a code project: the scheduler fetches each video from
its link here at posting time. The free tools live in the separate `tools` repository.

| Folder | What is in it |
|---|---|
| `inherit/` | Episodes of the "Inherit" AI-made drama series |

Rules for this repository:

- One folder per series or campaign, file names end in the version (`inherit_ep2_v3.mp4`).
- Do not rename, move or delete a file while a post that uses it is still scheduled; the post would fail.
- A redone video gets a new file name instead of replacing the old file.
